# 子智能体管理：内置与自定义功能区分

## 需求确认
- **内置子智能体（Explore、general-purpose）**：不提供启用/禁用开关（始终启用、不可删除），但**可以修改模型**；不设置模型时使用默认模型。
- **自定义子智能体**：保留启用/禁用、编辑、删除功能（现状不变）。
- 顺带修复现有 bug：`SubagentCardList.tsx` 目前对所有行（含内置/文件）都渲染启用开关，后端必然报错。

## 实现方案

### 1. DB 层 — `packages/server/src/db/schema.ts` + `db/index.ts`
新增表 `builtin_subagent_overrides`：
- `id` PK、`userId`、`name`（内置子智能体名）、`model`（可空 TEXT）、`createdAt/updatedAt`
- `uniqueIndex(userId, name)`，命名风格照抄 `user_subagents`
- `db/index.ts` 增加 `getBuiltinOverride / upsertBuiltinOverride / listBuiltinOverrides(userId)`（建表 DDL 用现有 idempotent 建表模式）

### 2. Core — `packages/core/src/agent.ts`
- `MakeGraphOptions` 新增 `builtinSubagentOverrides?: Record<string, string | null>`（name → model 覆盖，null = 用默认）
- 构图时 `for (const sa of BUILTIN_SUBAGENTS)` 循环中：`const model = overrides[sa.name] !== undefined ? overrides[sa.name] : sa.model`，`if (model) spec.model = model`（`injectedBy: "sdk"` 的 general-purpose 覆盖暂不生效，注释说明）
- 将 overrides 纳入 graph 签名缓存 key（`subagentSignature` 附近），保证改模型后不会命中旧图

### 3. Server — `subagent.service.ts` + `routes/config.ts` + `routes/chat.ts`
- service：
  - `getSubagentDetail` / 列表接口合并内置条目时应用用户 override：`model = override ?? b.model ?? null`
  - `updateBuiltinSubagentModel(userId, name, model|null)`：校验 name ∈ `BUILTIN_SUBAGENTS`，写 override 表
  - `updateSubagent` 改造：目标是内置条目（非 user-defined 且匹配 builtin 名）且 patch 只含 `model` 时 → 走 override；其他字段报 `"内置子智能体仅支持修改模型"`
- `routes/config.ts`：`builtInSubagentEntry` 接收 override 参数；PUT `/subagents/:name` 不变（由 service 分流）；模型修改后调用 `clearGraphCache()`（config 变更影响图形状，按 AGENTS.md 要求）
- `routes/chat.ts`：`resolveUserSubagents` 旁新增 `resolveBuiltinOverrides(userId)`，传入 `makeGraph` 的新 option

### 4. Web 前端
- `SubagentCardList.tsx`：`row` 的 `Switch` 仅在 `origin === "user-defined"` 时渲染；内置/文件行右侧改为显示只读 Tag（如「内置 · 默认模型」/模型名）
- `SubagentDetail.tsx`：
  - 内置条目：隐藏 Switch 与删除按钮；显示「修改模型」按钮，弹小 Modal（Select/Input 填 `provider:model`，留空 = 恢复默认模型），调 `sdk.updateSubagent(name, { model })`
  - 文件条目：完全只读（现状）
  - 自定义条目：现状不变（Switch/编辑/删除）
  - 「模型覆盖」卡片改为始终显示：`值 = model ?? "默认模型"`
- `ExtensionForms.tsx`：编辑页对内置条目不暴露入口（详情页模型 Modal 已覆盖需求），无需改动
- `tentacle`：`SubagentEntry` 类型不变；如 PUT 方法签名已支持 `{ model }` patch 则无需改动，否则补充

### 5. 验证
- 各包 `tsc --noEmit`（core → server → tentacle → web 顺序，先 build core/tentacle）
- 手动路径：改 Explore 模型 → 新会话生效；清空 → 回默认；自定义子智能体启停/删除不受影响
