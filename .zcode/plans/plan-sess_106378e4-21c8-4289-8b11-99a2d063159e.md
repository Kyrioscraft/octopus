## Problem

The TUI shows a "Thinking..." spinner (`Loading` component) anchored at the **bottom** of the screen (chrome region between messages and input). The user wants the thinking indicator to appear **inline** within the assistant message area — where the AI's response will eventually appear — not as a separate bottom-anchored element.

The inline `AssistantMessageView` already renders "⠋ Thinking..." correctly when the assistant message has no content and isn't finalized (messages.tsx:166-168). The fix is to remove the bottom indicator and ensure the inline one appears immediately when the user sends a message.

## Changes

### 1. `tui/src/components/screens/main-screen.tsx`
- **Remove** the `<Loading status={spinnerStatus} />` block from the chrome region (lines 119-123)
- **Remove** the `Loading` import (line 16)
- **Remove** `spinnerStatus` from destructured props since it's no longer used here (it's still passed to `StatusBar`)

### 2. `tui/src/hooks/use-chat-session.ts` — `executeMessage` function
- After creating the user message, immediately create a **placeholder assistant message** with:
  - `id`: `assistant_${Date.now()}`
  - `role`: `"assistant"`
  - `content`: `""`
  - `metadata`: `{ finalized: false }`
- Pass this pre-created message ID to `executeAgentTask` via `ExecutionContext`

### 3. `tui/src/tui-adapter.ts`
- Add `assistantMessageId?: string` to the `ExecutionContext` interface
- In `executeAgentTask`: initialize `state.assistantMessageId` from `ctx.assistantMessageId` (instead of `null`)
- In `resumeAgentTask`: same treatment
- In `processStreamEvent` (`loading` case, ~line 319): when `state.assistantMessageId` is already set and the first token arrives, use `callbacks.updateMessage()` instead of `callbacks.addMessage()`
- In `finalizeStream`: ensure the assistant message is properly finalized with `metadata.finalized = true`

### 4. `tui/src/components/loading.tsx`
- **No change** — still used by `connecting-screen.tsx` for the "Checking server health..." indicator

## Result

After the fix:
- User sends a message → placeholder assistant bubble appears immediately with inline "⠋ Thinking..."
- Streaming tokens arrive → inline content updates in place
- Stream completes → message finalized, spinner removed
- No more bottom-anchored thinking indicator
- The `StatusBar` still receives `spinnerStatus` for phase display
