## 目标

将 **Todo 待办徽章** 和 **子智能体徽章** 从输入框工具栏（InputBar）迁移到对话区域顶部导航栏（ChatHeader）的右侧，位于"展开/收起伴侣面板按钮"的**左侧**。两者均采用"按需生成"策略——仅在有待办事项 / 有子智能体活动时才显示对应图标。

最终导航栏右侧布局（从左到右）：
```
[待办徽章]  [子智能体徽章]  [伴侣面板切换按钮]  [GitHub链接]
   (有todo)     (有subagent)
```

## 改动清单

### 1. 新建子智能体徽章组件（镜像 TodoBadge）
**新建** `web/src/components/chat/header/SubagentBadge.tsx`
- 镜像现有 `TodoBadge.tsx` 的结构（为保持一致性，新徽章也一并移入 `header/` 目录）
- Props: `subagents: SubagentEvent[]`
- 空数组时 `return null`（无子智能体不显示）
- 图标 `RobotOutlined`，显示计数（如 `2`）或正在执行的数量
- 着色逻辑：有 streaming 中的子智能体 → `var(--color-info-700)` 蓝色；全部 done → `var(--color-success-700)` 绿色
- 点击调用 `useChatStore` 的 `openCompanionTab("subagents")` 打开子智能体面板（不带 refId，进入概览/跟随最新 run）

### 2. 移动 TodoBadge 到 header 目录（保持组件复用）
**移动** `web/src/components/chat/input/TodoBadge.tsx` → `web/src/components/chat/header/TodoBadge.tsx`
- 组件逻辑不变（仅改 import 路径），保持 `CheckSquareOutlined` + `done/total` 显示 + 点击打开 todos 面板

### 3. ChatHeader 增加徽章 props 与渲染
**修改** `web/src/components/chat/ChatHeader.tsx`
- 新增 props: `todos: TodoItem[]` 和 `subagents: SubagentEvent[]`
- 在右侧 flex 容器内、**伴侣面板切换按钮（第 37 行 Tooltip）之前**插入：
  ```tsx
  <TodoBadge todos={todos} />
  <SubagentBadge subagents={subagents} />
  ```
- 两者都是空数据返回 `null`，所以无待办/无子智能体时导航栏保持原样

### 4. Chat.tsx 传递数据到 ChatHeader
**修改** `web/src/pages/Chat.tsx`
- 给 `<ChatHeader>` 增加 `todos={chat.todos}` 和 `subagents={chat.allSubagents}`
- 数据源已就绪（`useChat` 返回 `todos` 和 `allSubagents`），无需改 hooks

### 5. InputBar 移除 TodoBadge
**修改** `web/src/components/chat/input/InputBar.tsx`
- 删除第 212-214 行 `<TodoBadge todos={todos} />` 渲染
- 删除 `todos` prop（第 58 行）及相关 import（第 9 行 `TodoBadge`）
- 清理未使用的 `TodoItem` 类型 import

### 6. Chat.tsx 移除传给 InputBar 的 todos
**修改** `web/src/pages/Chat.tsx`
- 删除第 114 行 `todos={chat.todos}`（传给 InputBar 的）

## 不需要改动
- `useChat.ts`（数据源 `todos` / `allSubagents` 已就绪）
- `stores/chat.ts`（`openCompanionTab` 已支持 `"todos"` 和 `"subagents"`）
- companion 面板内的 `TodoPanel` / `SubagentPanel`（点击徽章后仍由这些面板渲染详情）
- `companion/types.tsx` 的 `TAB_META`

## 验证方式
- `cd web && npm run build`（即 `tsc -b && vite build`）确认类型与构建通过
- 手动验证：发起一个会触发 todo 的对话，确认徽章出现在导航栏而非输入框；发起调用子智能体的对话，确认子智能体徽章按需出现
