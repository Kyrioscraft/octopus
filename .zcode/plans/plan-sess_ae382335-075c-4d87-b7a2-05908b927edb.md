# Claude Code 风格 UI 改进计划

基于对 Claude Code 界面的详细调研，实现以下 3 项改进：

---

## P0: 推理块可折叠（Collapsible Reasoning Block）

**文件**: `tui/src/components/messages.tsx`

**改动**：
1. 添加 `useInput` import（从 ink）
2. 将 `ReasoningBlock` 改为 `CollapsibleReasoningBlock`：
   - `useState` 控制 `expanded`（默认 false）
   - `useInput` 捕获 Tab 键切换 expanded
   - 折叠态：显示第一行 + dimmed "—— 展开 (N lines)"
   - 展开态：显示所有行 + dimmed "—— 折叠"
   - 每行前缀 `┄`，dimmed italic 样式
3. 由于 `<Static>` 内的组件 hooks 不执行，只有活跃区域（streaming 中）的推理块会响应 Tab 键。完成后移入 Static 保持最后状态。

---

## P2: Explore Widget 工具执行行紧凑化

**文件**: `tui/src/components/explore-widget.tsx`

**改动**：
1. 给 `ToolExecRow` 的工具行添加 `marginLeft={2}` 统一缩进
2. 确保工具名和参数间距一致
3. 结果摘要行也使用一致的缩进

---

## P3: 输入提示符对齐 Claude Code

**文件**: `tui/src/config-ui.ts`

**改动**：
1. `UNICODE_GLYPHS.prompt` 从 `"❯"` 改为 `">"`
2. `ASCII_GLYPHS.prompt` 保持 `">"` 不变

---

## P4: 权限弹窗优化

**文件**: `tui/src/components/approval.tsx`

**改动**：
1. 标题从 `⚙ Tool Approval Required` 改为更紧凑的格式
2. 选项行格式对齐 Claude Code：`→ [y] Approve`
3. 提示文本简化

---
