## Summary

The TUI startup error (`Failed to load recent thread list — Error: Not Found`) is caused by the TUI connecting to port **5050**, which is held by an unrelated/stale process on this machine. `server-manager.ts` blindly reuses whatever is already listening on the configured port, so it never spawns our server and the foreign server returns Hono's plain-text `404 Not Found` for `GET /api/chat/threads`. The route itself is correctly registered in our codebase (source + dist).

**Fix:** change the app's default port from the collision-prone `5050` to a dedicated **`9876`** everywhere it is hardcoded, so the TUI/server talk to our own server.

## Build/run after edits
1. `cd server && npm run build` (also `cd tui && npm run build` if running compiled TUI)
2. Ensure nothing of ours is on the old 5050 or the new 9876: `netstat -ano | findstr :9876`
3. Restart TUI — `server-manager` will probe 9876, find nothing foreign, and spawn our server there.
