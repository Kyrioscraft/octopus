## 问题

antd 在较新版本中弃用了 `Modal` 的 `destroyOnClose` 属性，改用 `destroyOnHidden`。运行时控制台出现警告：

```
Sidebar.tsx:548 Warning: [antd: Modal] `destroyOnClose` is deprecated. Please use `destroyOnHidden` instead.
```

## 修复方案

将 `web/src` 中所有 `Modal` 上的 `destroyOnClose` 替换为 `destroyOnHidden`。共 4 处，均为同一改法：

| 文件 | 行号 |
|------|------|
| `web/src/components/Sidebar.tsx` | 552 |
| `web/src/components/Sidebar.tsx` | 648 |
| `web/src/components/DirBrowserModal.tsx` | 111 |
| `web/src/components/WorkspaceDrawer.tsx` | 428 |

这两个 prop 语义一致（关闭时销毁内部子组件），`destroyOnHidden` 是 antd 为与 `open` 语义对齐而引入的替代名，属纯重命名，无行为变化。

## 验证

修改后在 `web` 目录执行 `npm run lint`（即 `tsc --noEmit`）确认无类型错误，刷新前端确认控制台不再出现该警告。
