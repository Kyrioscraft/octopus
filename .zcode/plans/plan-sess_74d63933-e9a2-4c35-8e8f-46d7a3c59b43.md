# Web 界面深色主题实现计划

## 目标
在 web 端新增深色主题，支持「浅色 / 深色 / 跟随系统」三种模式，在「设置 → 常规」页面新增「外观」卡片进行切换，主题偏好持久化到 localStorage，并在应用启动时即应用（避免白闪）。

## 设计决策
- **三态模式**：`light | dark | system`。`system` 通过 `matchMedia('(prefers-color-scheme: dark)')` 跟随系统，并监听系统变化实时切换。
- **驱动机制**：根 `<html>` 元素加 `data-theme="light|dark"` 属性（system 解析成实际值后写入）。CSS 用 `[data-theme="dark"]` 选择器覆盖变量；antd 用 `theme.darkAlgorithm`。
- **持久化**：遵循项目惯例（chat.ts 手动 localStorage，不用 zustand persist），key 为 `octopus.theme-mode`。
- **UI 控件**：antd `Segmented`，三段：☀ 浅色 / 🌙 深色 / 🖥 跟随系统。
- **覆盖范围**：完整——含 markdown 代码块高亮（换 github-dark）与 diff viewer。

## 改动清单（6 个文件，1 个新建）

### 1. 新建 `web/src/stores/theme.ts`（核心）
Zustand store，仿 `chat.ts` 手动 localStorage 模式：
- state：`mode: ThemeMode`（'light'|'dark'|'system'）、`resolved: 'light'|'dark'`（实际生效值）
- actions：`setMode(mode)` —— 写 localStorage + 更新 `document.documentElement.dataset.theme`
- 初始化时读 `localStorage['octopus.theme-mode']`（默认 `'system'`），解析出 resolved 并立即设置 `data-theme`
- 若 `mode === 'system'`，注册 `matchMedia` change 监听器，变化时更新 resolved 与 DOM

### 2. 改 `web/src/styles/theme.css`
在 `:root { ... }` 块之后新增：
```css
[data-theme="dark"] {
  /* 反转灰阶：原 --gray-0(白) → 深色背景，--gray-1000(黑) → 浅色文字 */
  --gray-0: #151616;       /* 主背景 */
  --gray-10: #1a1b1b;
  --gray-25: #1e1f1f;
  --gray-50: #222323;      /* 次级背景/卡片 */
  --gray-100: #2a2b2b;     /* 边框/分隔 */
  --gray-150: #2f3030;
  --gray-200: #3a3b3b;     /* 滚动条 thumb */
  --gray-300: #4c4d4d;
  --gray-400: #6c6e6e;
  --gray-500: #979999;     /* 次要文字 */
  --gray-600: #b6b9b9;
  --gray-700: #dfe1e1;
  --gray-800: #eef0f0;     /* 补齐 InfoRow 用到的缺失变量 */
  --gray-900: #f2f4f4;     /* 主文字 */
  --gray-1000: #fbfcfc;    /* 标题文字 */
  /* 阴影在深色下减弱/加深底色 */
  --shadow-0: rgba(0,0,0,0.2);
  --shadow-1: rgba(0,0,0,0.3);
  --shadow-2: rgba(0,0,0,0.4);
  --shadow-3: rgba(0,0,0,0.5);
  /* brand 绿色在深色下适当提亮以保持对比 */
  --main-color: #52c41a;
  --main-600: #73d13d;
  --main-700: #95de64;
  /* 语义色背景加深、文字提亮 */
  --color-error-50: #2a1212;  --color-error-100: #58181c;
  --color-success-50: #162312; --color-success-100: #23480f;
  --color-warning-50: #2b2111; --color-warning-100: #594214;
  --color-info-50: #111d2c;    --color-info-100: #15395b;
}
body[data-theme="dark"] { color-scheme: dark; }  /* 让原生表单控件/滚动条走深色 */
```
（具体色值会在实现时微调确保对比度达 WCAG AA。）

### 3. 改 `web/src/App.tsx`
- import theme store：`import { useThemeStore } from "./stores/theme.js";`
- 在 `App` 组件内 `const resolved = useThemeStore(s => s.resolved);`
- `algorithm: resolved === 'dark' ? antdTheme.darkAlgorithm : antdTheme.defaultAlgorithm`
- `components.Select` 的硬编码浅色配色（`optionSelectedBg` 等）改为跟随主题：用三元判断或直接删除让 antd 走算法默认值（推荐删除，darkAlgorithm 会自动给出合适的深色配色）

### 4. 改 `web/src/main.tsx`
在 `createRoot(...).render()` **之前**，同步执行一次主题初始化（避免首屏白闪）：
```tsx
import { initTheme } from "./stores/theme.js";
initTheme();  // 同步读 localStorage + 设置 data-theme
```
store 的 `initTheme()` 函数：读 mode → 解析 resolved → 写 `document.documentElement.dataset.theme`。store 创建时也会自动调用一次。

### 5. 改 `web/src/styles/markdown.css`
代码块高亮：文件顶部内联的是 highlight.js **github-light**。在文件末尾新增 `[data-theme="dark"] .md-body .hljs { ... }` 覆盖块，提供 github-dark 风格配色（背景 `#0d1117`，关键字/字符串/注释等重定义）。其余 markdown 正文样式已用 CSS 变量，自动适配。

### 6. 改 `web/src/components/settings/GeneralSettingsSection.tsx`
在「工具开关」卡片**之前**新增「外观」卡片：
```tsx
<Card title="外观">
  <SettingRow icon={<BulbOutlined />} label="主题模式" description="选择界面配色，或跟随系统">
    <Segmented
      size="small"
      value={mode}
      onChange={(v) => setMode(v as ThemeMode)}
      options={[
        { label: '☀ 浅色', value: 'light' },
        { label: '🌙 深色', value: 'dark' },
        { label: '🖥 系统', value: 'system' },
      ]}
    />
  </SettingRow>
</Card>
```
（SettingRow 复用现有「工具开关」的行布局样式：icon + label/description + 控件。）
- import `Segmented` from antd，`BulbOutlined` from icons，`useThemeStore` from stores。
- 不需要后端接口、不写 saving 状态（纯前端，切换即时生效）。

### 7. 改 `web/src/components/toolcalls/cards/FileEditCard.tsx`（diff viewer）
- 第 103 行 `useDarkTheme={false}` → `useDarkTheme={resolved === 'dark'}`，从 theme store 读 resolved。
- 第 107-120 行 `variables.light` 是手写浅色配色（用 CSS 变量）。新增 `variables.dark` 配色块，按 resolved 选择。或简化为始终用 CSS 变量配 `useDarkTheme` 跟随主题（视 diff-viewer 库对 variables 的处理而定，实现时确认）。

## 验证方式
按 AGENTS.md，web 包无测试，用 `cd web && npm run lint`（即 `tsc --noEmit`）验证类型；再 `npm run dev` 手动验证：
1. 设置 → 常规 → 外观，切到「深色」，全页面变深色、无白闪。
2. 切到「跟随系统」，改系统深浅色，页面实时跟随。
3. 刷新页面，主题偏好保留。
4. 检查代码块、diff viewer、antd 弹窗/下拉在深色下可读。

## 不在范围内
- 不新增后端接口、不改 tentacle SDK、不改路由。
- 不改 Sidebar/ChatPage 等组件的内联样式（它们已用 CSS 变量，自动适配；若发现个别硬编码颜色，实现时顺手修正）。
- 不做主题色自定义（仅深浅切换，不改品牌绿）。
