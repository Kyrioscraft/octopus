# 重构方案：整理 web/src/components/ 根目录

## 背景
`web/src/components/` 根目录当前散落 7 个文件，全部偏功能化（无真正通用组件）。现有 feature-subdir 风格已成型（`companion/`、`toolcalls/`、`timeline/`、`extensions/`、`settings/`、`widgets/`），本次按同样风格把根目录文件按功能聚合到新子目录。

## 目标目录结构
```
components/
├── chat-input/        ← 新建（聊天输入栏组件）
│   ├── AskPanel.tsx
│   └── TodoBadge.tsx
├── sidebars/          ← 新建（三个 Sidebar）
│   ├── Sidebar.tsx
│   ├── ExtensionsSidebar.tsx
│   └── SettingsSidebar.tsx
├── workspace/         ← 新建（工作区相关）
│   ├── DirBrowserModal.tsx
│   └── WorkspaceFileTree.tsx
├── companion/         (现有，不变)
├── toolcalls/         (现有，不变)
├── timeline/          (现有，不变)
├── extensions/        (现有，不变)
├── settings/          (现有，不变)
└── widgets/           (现有，不变)
```

根目录移动后**不再保留任何 .tsx 文件**（全部进入子目录）。

## 执行步骤

### Step 1: 用 `git mv` 移动 7 个文件
- `git mv components/AskPanel.tsx components/chat-input/AskPanel.tsx`
- `git mv components/TodoBadge.tsx components/chat-input/TodoBadge.tsx`
- `git mv components/Sidebar.tsx components/sidebars/Sidebar.tsx`
- `git mv components/ExtensionsSidebar.tsx components/sidebars/ExtensionsSidebar.tsx`
- `git mv components/SettingsSidebar.tsx components/sidebars/SettingsSidebar.tsx`
- `git mv components/DirBrowserModal.tsx components/workspace/DirBrowserModal.tsx`
- `git mv components/WorkspaceFileTree.tsx components/workspace/WorkspaceFileTree.tsx`

（先 `mkdir` 新目录；`git mv` 保留历史。）

### Step 2: 更新导入路径（共 5 处外部 + 2 处内部）

**外部调用方（2 个文件，5 行）：**

`web/src/layouts/AppLayout.tsx`:
```
- import { Sidebar } from "../components/Sidebar.js";
- import { ExtensionsSidebar } from "../components/ExtensionsSidebar.js";
- import { SettingsSidebar } from "../components/SettingsSidebar.js";
+ import { Sidebar } from "../components/sidebars/Sidebar.js";
+ import { ExtensionsSidebar } from "../components/sidebars/ExtensionsSidebar.js";
+ import { SettingsSidebar } from "../components/sidebars/SettingsSidebar.js";
```

`web/src/pages/Chat.tsx`:
```
- import { AskPanel } from "../components/AskPanel.js";
- import { TodoBadge } from "../components/TodoBadge.js";
+ import { AskPanel } from "../components/chat-input/AskPanel.js";
+ import { TodoBadge } from "../components/chat-input/TodoBadge.js";
```

**内部调用方（2 处，相对路径需重算）：**

`components/sidebars/Sidebar.tsx`（从 `./DirBrowserModal.js` → `../workspace/DirBrowserModal.js`）:
```
- import { DirBrowserModal } from "./DirBrowserModal.js";
+ import { DirBrowserModal } from "../workspace/DirBrowserModal.js";
```

`components/companion/panels/FilesPanel.tsx`（从 `../../WorkspaceFileTree.js` → `../../workspace/WorkspaceFileTree.js`）:
```
- import { WorkspaceFileTree } from "../../WorkspaceFileTree.js";
+ import { WorkspaceFileTree } from "../../workspace/WorkspaceFileTree.js";
```

### Step 3: 检查移动文件内部相对引用
需检查被移动的文件是否用 `../` 引用了 stores/、types/ 等：
- `TodoBadge.tsx` 原本 `import { useChatStore } from "../stores/chat.js"` 和 `import type { TodoItem } from "./companion/types.js"` → 移到 `chat-input/` 后需改为 `../../stores/chat.js` 和 `../companion/types.js`
- `AskPanel.tsx`、`Sidebar.tsx`、`WorkspaceFileTree.tsx`、`DirBrowserModal.tsx` 中所有 `../` / `./` 相对引用均需逐一核对并相应调整为多一层或多一层。

逐文件 grep `from "\.\.` 和 `from "\.`，调整深度。

### Step 4: 验证
- 在 `web/` 下运行 `npm run lint`（= `tsc --noEmit`），确保无类型/导入错误。
- 如有 `web/tsconfig.tsbuildinfo` 残留，可一并清理后重新构建确认。
- 不做功能改动，不动逻辑、不动样式。

## 不在本次范围内
- 不合并 ExtensionsSidebar / SettingsSidebar 的重复 nav-shell 代码（结构性重构，超出"分类"诉求）。
- 不引入 `@/` 路径别名（全仓库统一事项，单独 PR 更合适）。
- 不新建 barrel `index.ts`（与现有各 subdir 无 barrel 的风格一致）。
- `widgets/`、`companion/` 等现有子目录不动。
