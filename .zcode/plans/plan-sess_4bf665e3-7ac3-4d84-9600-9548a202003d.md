# 统一所有 row 的图标显示规则

## 统一规则（三个 row 一致）
| 状态 | 显示图标 | 颜色 |
|---|---|---|
| 进行中（running/streaming/聚合 pending>0） | `LoaderCircle`（旋转） | `var(--color-info-700)` |
| 完成（done/allDone） | 类型图标 | **`var(--gray-400)`**（最暗，统一） |
| 错误（error/errored>0） | `CircleX` | `var(--color-error-500)` |
| 待处理（pending 单工具） | `LoaderCircle`（旋转，与 running 合并） | `var(--color-info-700)` |

> 用户确认：pending 也用 loader（不再用 Clock）。完成态类型图标统一调暗到 `var(--gray-400)`。

## 三个文件的改动

### 1. `ToolCallRow.tsx` — `RowIcon` + 外层 span
**问题**：
- 完成态类型图标继承外层 `<span color: var(--gray-600)>`（太深）
- pending 用 Clock，应改 loader

**改法**：
- `RowIcon` 的 `done` 分支：给类型图标显式包一层 `var(--gray-400)` 颜色（或在 `<span>` 上覆盖）
- `RowIcon` 的 `pending` 分支：`Clock` → `LoaderCircle`（与 running 合并，都用 `var(--color-info-700)`）
- 外层 `<span style={{ color: "var(--gray-600)" }}>`：移除强制颜色（或改为不影响图标的设置），让 RowIcon 内部显式颜色生效
- 移除未使用的 `Clock` import

具体 `RowIcon`：
```tsx
function RowIcon({ name, status }) {
  switch (status) {
    case "done":
      return <span style={{ color: "var(--gray-400)", display: "inline-flex", alignItems: "center" }}>{getToolIcon(name)}</span>;
    case "error":
      return <CircleX style={{ color: "var(--color-error-500)" }} />;
    case "running":
    case "pending":
    default:
      return <LoaderCircle style={{ color: "var(--color-info-700)" }} />;
  }
}
```
外层 span（行 90）：`color: "var(--gray-600)"` → 移除（避免覆盖完成态的 gray-400），仅保留 `display/alignItems`。

### 2. `SubagentRow.tsx` — `leadIcon`
**问题**：完成态 `Bot` 无显式颜色（继承 gray-500），尺寸 fontSize:12，与 ToolGroupBar 的 13 不一致。

**改法**：
- `Bot` 加显式 `color: "var(--gray-400)"`，fontSize 统一 `13`：
```tsx
const leadIcon = streaming ? (
  <LoaderCircle style={{ color: "var(--color-info-700)" }} />
) : (
  <Bot style={{ fontSize: 13, color: "var(--gray-400)" }} />
);
```

### 3. `TurnEvents.tsx` — `ToolGroupBar` 的 `leadIcon`
**问题**：已经基本符合目标（done=Search gray-400, pending>0=LoaderCircle, error=CircleX），但 else 分支还用 Clock。

**改法**：
- else 分支（兜底等待，理论上 `pending===0 && !allDone` 的边缘情况）的 `Clock` → `LoaderCircle`，保持与其他 row 的 pending 一致
- 移除未使用的 `Clock` import
- 顺手修正注释：`FileText` → `Search`（注释与代码不符）
